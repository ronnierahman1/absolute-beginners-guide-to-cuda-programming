# **Chapter 10 – A Visual Finale (Mandelbrot Fractal)**

This final chapter brings together everything you have learned throughout the book.
You will write CUDA kernels that generate one of the most iconic mathematical images ever—the **Mandelbrot set**.
Each program in this folder illustrates a step toward the finished, colored, and optimized fractal renderer.

---

## What You Will Learn

* Map image pixels to points on the **complex plane**.
* Implement the iteration ( z_{n+1} = z_n^2 + c ) efficiently on the GPU.
* Detect **divergence** using an escape radius of 2.
* Apply a fixed **iteration cap** to guarantee termination.
* Color pixels using either **grayscale** or **palette-based** schemes.
* Write results to simple, portable image formats (**PGM** / **PPM**).
* Verify GPU results with a **CPU reference function**.
* Convert generated images to **PNG** for easy viewing on any platform.

---

## File List

| File                                 | Description                                                                                                     |     |      |          |
| ------------------------------------ | --------------------------------------------------------------------------------------------------------------- | --- | ---- | -------- |
| **mandelbrot.cu**                    | Basic Mandelbrot renderer in **grayscale** (PGM output). Ideal first step.                                      |     |      |          |
| **mandelbrot_color.cu**              | Adds **color** via simple HSV mapping and supports PPM output.                                                  |     |      |          |
| **mandelbrot_final.cu**              | Polished, educational version — grayscale + color, ASCII or binary (P2/P3/P5/P6), CPU verification, and timing. |     |      |          |
| **mandelbrot_final_palette_pack.cu** | “Palette-pack edition.” Adds runtime palette selection (`grayscale                                              | hsv | fire | ocean`). |
| **mandelbrot.png**                   | Example **grayscale** render – reference output from `mandelbrot.cu`.                                           |     |      |          |
| **mandelbrot_color.png**             | Example **colored** render – reference output from `mandelbrot_color.cu`.                                       |     |      |          |
| **mandelbrot.pgm**                   | Raw grayscale PGM file generated by `mandelbrot.cu`.                                                            |     |      |          |
| **mandelbrot.ppm**                   | Raw color PPM file generated by `mandelbrot_color.cu`.                                                          |     |      |          |
| **pgm2png.py**                       | Python utility that converts `.pgm → .png` using Pillow.                                                        |     |      |          |
| **ppm2png.py**                       | Python utility that converts `.ppm → .png` using Pillow.                                                        |     |      |          |

---

## Build and Run

### Linux / macOS

```bash
nvcc mandelbrot.cu -o mandelbrot
nvcc mandelbrot_color.cu -o mandelbrot_color
nvcc mandelbrot_final.cu -o mandelbrot_final
nvcc mandelbrot_final_palette_pack.cu -o mandelbrot_final_palette_pack
```

### Windows (PowerShell)

```powershell
nvcc .\mandelbrot.cu -o mandelbrot.exe
nvcc .\mandelbrot_color.cu -o mandelbrot_color.exe
nvcc .\mandelbrot_final.cu -o mandelbrot_final.exe
nvcc .\mandelbrot_final_palette_pack.cu -o mandelbrot_final_palette_pack.exe
```

### Example runs

```bash
# Grayscale Mandelbrot
./mandelbrot --width 1024 --height 768 --max-iter 200 --out mandelbrot.pgm

# Color Mandelbrot (HSV)
./mandelbrot_color --width 1024 --height 768 --max-iter 500 --out mandelbrot.ppm

# Full-featured version
./mandelbrot_final --width 1920 --height 1080 --max-iter 800 \
  --color --smooth --binary --out mandelbrot_color.ppm

# Palette-pack edition (choose palette)
./mandelbrot_final_palette_pack --width 1920 --height 1080 --max-iter 800 \
  --color --smooth --binary --palette fire --out mandelbrot_fire.ppm
```

---

## Palette Options (when using palette-pack edition)

| Palette       | Description                              |
| ------------- | ---------------------------------------- |
| **grayscale** | Black → white gradient.                  |
| **hsv**       | Rainbow cycle – classic fractal palette. |
| **fire**      | Black → red → orange → yellow → white.   |
| **ocean**     | Deep blue → teal → light blue → white.   |

---

## Viewing Images

### Windows

* **IrfanView** (recommended) or **GIMP** open `.pgm` and `.ppm` directly.
* Or convert to PNG with the provided script:

  ```powershell
  python pgm2png.py mandelbrot.pgm
  python ppm2png.py mandelbrot.ppm
  ```

### Linux / macOS

* Use the default image viewer:

  ```bash
  eog mandelbrot.pgm        # GNOME
  display mandelbrot.ppm    # ImageMagick
  ```
* Or convert to PNG:

  ```bash
  convert mandelbrot.pgm mandelbrot.png
  convert mandelbrot.ppm mandelbrot_color.png
  ```

---

## Reference Images Included

* **mandelbrot.png** – sample grayscale result.
* **mandelbrot_color.png** – sample colored result.
* **mandelbrot.pgm** and **mandelbrot.ppm** – raw outputs for learners to open or convert.

These help you verify that your build and rendering match the expected output.

---

## Verification and Exploration

* Run `--verify 6` to compare a few pixels against CPU reference values.
* Increase `--max-iter` or use `--zoom-cx`, `--zoom-cy`, `--zoom-scale` (if implemented) to explore deep regions.
* Try different palettes and observe how color mapping changes perception of detail.

---

## Next Steps

* Add **Julia set** mode using `--julia CR CI`.
* Implement **smooth coloring** or **lighting effects** for more depth.
* Experiment with **block sizes**, **precision modes**, or **timing** for performance study.
* Use **pgm2png.py** and **ppm2png.py** to automate output conversions for reports or galleries.

---

## Summary

This chapter concludes the beginner’s CUDA journey.
From the first grayscale kernel to the full-color palette-driven renderer, you have learned every essential concept—thread mapping, iteration, memory handling, synchronization, and visual output.
The Mandelbrot set is both your final test and your first real canvas in CUDA programming.
